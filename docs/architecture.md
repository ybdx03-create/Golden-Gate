# 아키텍처와 데이터 한계

브라우저(React/Vite) → Express API → 로컬 PostgreSQL. 가격 데이터는 수동 CSV 입력 또는 사용자가 발급한 Alpha Vantage 키의 **일별 과거 OHLCV**만 가져온다. 실시간/프리마켓 호가는 제공하지 않는다. 산업 자금 흐름은 거래대금 변화의 **대용 지표**이며 기관 순매수로 해석하지 않는다.

분석 엔진은 최소 21개 일봉이 있는 종목에 20일 수익률, 직전 20일 대비 거래량, 최근 거래대금과 이전 20일 평균의 비율을 계산한다. 재무 정보가 입력되면 매출 성장 및 밸류에이션을 보조 지표로 표시한다. 매수 후보에는 주가 5 USD 이상과 직전 20일 평균 거래대금 500만 USD 이상을 요구한다. 이 기준은 수익을 보장하지 않으며 유동성 필터다. 추천은 규칙 기반 후보 분류이며 확률 예측을 주장하지 않는다. 분석 실행과 입력 종료일을 저장해 사후 평가할 수 있다.

실제 주문 API는 없다. 체결은 사용자가 수동으로 기록한다. 포트폴리오 손익은 FIFO 원가, 수수료, 사용자가 입력한 HKD/USD 환율로 계산한다. 데이터가 없으면 성과를 추정하지 않는다.

향후 작업: SEC 공시 기반 시점별 재무 데이터, 거래소 공식 캘린더 연동, 데이터 라이선스 검토, 조정 가격과 상장폐지 종목을 포함한 정식 워크포워드 검증, 사용자 인증 및 접근 제어, 브로커 명세서 가져오기. 운영 환경 공개 전 사용자 인증이 필요하다.
