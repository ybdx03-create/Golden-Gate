# 규칙 모델과 검증 방법

## 현재 분석 모델 (`rules-v1.0.0`)

이 모델은 **예측 확률을 생성하지 않는 규칙 기반 후보 분류기**다. 매일 미국 동부 시간 08:45에 저장된 완료 일봉을 사용한다. 분석일 당일 가격은 사용하지 않는다. 수동 입력 또는 Alpha Vantage 일별 원시 OHLCV를 사용하므로 장전 실시간 수급은 알 수 없다.

종목별 최근 21개 일봉에서 다음을 계산한다.

- 20거래일 수익률: `최근 종가 / 20일 전 종가 - 1`.
- 거래량 배율: 최근 거래량 / 이전 20개 일봉의 평균 거래량.
- 거래대금 대용 배율: 최근 `종가 × 거래량` / 이전 20개 일봉의 평균 `종가 × 거래량`.
- 입력된 매출 성장률, 순이익률, PER은 보조 점수다. 재무 값이 없으면 추측하지 않는다.

점수는 50점에서 시작해 위 지표를 제한된 범위로 더한다. 매수 후보는 점수 65 이상, 양의 20일 추세, 주가 5 USD 이상, 이전 20일 평균 거래대금 500만 USD 이상을 모두 만족해야 한다. 보유 종목의 약한 점수는 축소 검토, 비보유 종목의 약한 점수는 관망으로 표시한다. 이 임계값은 연구용 기본값이며 검증된 수익 확률이 아니다.

산업 화면은 관심 종목의 거래대금 배율 평균을 보여 준다. 이는 **자금 흐름 대용 지표**이고 ETF 순유입, 기관 순매수, 실제 돈의 유입액을 뜻하지 않는다.

## 과거 검증

백테스트는 시점 순서대로 이전 21개 일봉만 보고 후보를 고른다. 진입 당일 종가나 미래 재무 자료를 신호에 사용하지 않는다. 후보 중 최고 점수 종목 하나에 가상 자본의 10%를 다음 개장가에 투자하고 기본 5거래일 보유한다. 매수·매도 양측에 수수료와 슬리피지(각각 기본 10bp)를 반영한다. 보유 중 매일 종가로 평가해 최대 낙폭을 계산한다. 첫 70% 기간과 마지막 30% 보류 기간을 따로 보고한다.

이것은 고정 규칙의 **시간 순서 보류 검증**이다. 파라미터를 학습·재최적화하는 정식 워크포워드 검증은 아니다. 원시 일봉의 분할·배당 미조정, 생존 편향 가능성, 실제 체결 가능성과 세금·FX 미반영 때문에 표시 수익률을 실전 기대 수익률로 사용하면 안 된다. 각 실행의 파라미터와 결과는 DB에 저장한다.

## 사후 평가와 실제 계좌 성과

추천 사후 평가는 추천 기준 종가 이후 1·5·20거래일 원시 종가 수익률이다. 실제 체결이나 현금 흐름을 뜻하지 않는다. 실제 계좌의 실현 손익은 별도 `trades`에서 FIFO 원가, 체결 수수료, 체결 당시 HKD/USD 환율을 적용한다. 최신 일봉과 환율이 7일보다 오래되면 평가 자산을 숨긴다.

## 다음 검증 단계

1. 분할·배당 조정된 권리 처리 데이터와 과거 상장폐지 종목을 포함한 생존 편향 없는 유니버스를 확보한다.
2. 기업 공시의 **발표 시각**과 당시 이용 가능했던 버전을 저장한다.
3. 산업별 실제 ETF 자금 흐름 및 기관 거래 정보는 라이선스가 허용하는 데이터 제공처와 계약한 뒤 별도 지표로 추가한다.
4. 파라미터 선택과 평가 기간을 분리한 다중 워크포워드 검증을 수행한다.
5. 종가·환율 스냅샷으로 일일 손실 및 실제 고점 대비 낙폭을 측정한다.
